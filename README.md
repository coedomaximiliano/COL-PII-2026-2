# COL - PII

Repositorio público de la cátedra para que los alumnos suban el código de sus trabajos prácticos.

## Organización

Las entregas son **individuales**. Hay 3 TPs y un TP integrador. El código se organiza por trabajo práctico y, dentro de cada uno, por alumno (carpeta con tu usuario de GitHub):

```
TRABAJOS PRACTICOS/
  TP1/
    usuario1/
    usuario2/
  TP2/
    usuario1/
  TP3/
  TP INTEGRADOR/
```

Cada alumno tiene su propia carpeta dentro de cada TP.

## Cómo subir tu código

- **¿Primera vez usando Git?** Seguí la [guía paso a paso para alumnos](GUIA-ALUMNOS.md).
- Si ya sabés usar Git, el flujo resumido está en [CONTRIBUTING.md](CONTRIBUTING.md).
